# semana-05-py
Repositório desenvolvido para armazenar e organizar as atividades práticas da semana 05, utilizando Python e arquivos CSV para trabalhar com dados.

Arquivos do projeto:
`main.py` — arquivo principal do projeto, contendo o código Python desenvolvido para a atividade.
`dados.csv` — arquivo que contém um conjunto de dados organizados em colunas, utilizado para praticar a leitura, a organização e a manipulação de informações.
`README.md` — arquivo com a descrição e as informações gerais do projeto.

Sobre o arquivo dados.csv: O arquivo `dados.csv` apresenta uma tabela com dados fictícios de pessoas, organizados em diferentes colunas:

Nome: nome da pessoa.
E-mail: endereço de e-mail.
CPF: número de identificação utilizado como exemplo.
Telefone: número de contato.
Dados: informações adicionais, incluindo datas e textos.
Idade: idade informada para cada registro.

A imagem mostra cinco registros de exemplo, permitindo observar diferentes tipos de dados armazenados no arquivo. Alguns valores apresentam formatos variados ou inconsistências, como uma idade negativa, um texto no campo de idade e diferentes formatos de telefone e CPF. Esses exemplos podem ser utilizados para praticar a validação, a padronização e o tratamento de dados com Python.

Objetivo:
Praticar conceitos fundamentais de programação em Python, desenvolvendo habilidades de leitura de arquivos, manipulação de dados e identificação de possíveis inconsistências nas informações.
